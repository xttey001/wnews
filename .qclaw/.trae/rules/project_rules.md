### 2.1 代码规范

#### JavaScript
- **使用双引号** `"` 而非单引号
- **使用 Tab 缩进**（而非空格）
- **对象属性缩进**：使用 1 个 Tab 层级
- **数组项缩进**：使用 1 个 Tab 层级
- **末尾逗号**：对象/数组最后一项不加逗号
- **文件编码**：UTF-8 (无 BOM)

#### Python
- **遵循 PEP 8**
- **使用 4 空格缩进**
- **函数命名**：snake_case
- **类命名**：PascalCase
- **常量**：UPPER_SNAKE_CASE

#### HTML/CSS
- **CSS 变量命名**：--kebab-case
- **类名命名**：kebab-case
- **使用语义化标签**

1. **❌ 禁止修改 .trae/rules/project_rules.md**
   - 此文件是 AI 行为规范，只有用户能修改
   - AI 只能读取，禁止写入

   - 每个日期数据必须包含：悟空/沙僧/白龙马/八戒/唐僧

   - 每次更新 news-data.js 后必须同步更新 review.html
   - 复盘页面需要手动更新逐日准确率表格

5. **❌ 禁止破坏数据格式**
   - 不要改变 news-data.js 的结构
   - 每个模块的字段必须完整保留

6. **❌ 禁止使用框架/库**
   - 前端保持纯 Vanilla JS，不引入 React/Vue/Angular
   - 不引入 jQuery 等外部库

7. **❌ 禁止硬编码敏感信息**
   - API 密钥、密码等必须环境变量化

8. **❌ 禁止破坏性删除**
   - 删除文件前必须确认无引用
   - 优先使用注释而非删除

## 5. 开发流程

### 5.1 标准更新流程 (每日新闻)
```
1. 查看当前数据
   → 阅读 news-data.js 最新日期结构

2. 添加新日期数据
   → 确保包含完整五维模块
   → 复制已有日期结构修改

   → git add .

   → git push

8. 验证部署
   → 访问 https://xttey001.github.io/news-website/

```

## 8. 核心分析思维（必须遵循）

### 8.1 风险定义权博弈框架

> **核心原则：谁能定义风险，谁就能迫使别人进入避害模式**

#### 三层博弈结构
```
第一层：风险定义者（政府/机构/媒体）
    ↓ 定义风险/机会
第二层：被迫避害者（散户/跟风资金）
    ↓ 恐慌抛售/追涨
第三层：逆向布局者（聪明资金/你）
    ↓ 低位吸筹/高位出货
结果：当"被迫避害者"足够多时，"逆向布局者"收益最大
```

#### 真假风险识别矩阵

| 场景 | 风险定义者 | 动机判断 | 真假风险 | 操作策略 |
|------|-----------|---------|---------|---------|
| **高位+行政打压** | 监管层 | 防过热/控风险 | **假风险** | 逢低布局（行政低点） |
| **低位+行政利好** | 监管层 | 稳增长/托市场 | **假机会** | 逢高减仓（行政高点） |
| **上涨中+突发利空** | 媒体/机构 | 洗盘吸筹 | **假风险** | 观察反拉信号 |
| **长期打压+无人问津** | 市场共识 | 无 | **真机会** | 悄悄吸筹 |
| **利好兑现+不及预期** | 市场预期 | 物极必反 | **真风险** | 及时减仓 |

#### 关键识别信号

**真机会信号（无人问津时）：**
- 新闻面无人讨论（大事件往往是转移注意力的烟雾弹）
- 成交量萎缩至地量
- 散户讨论度极低
- 但基本面未恶化
- **长期被打压的板块 = 洗盘吸筹**

**假风险信号（被定义的风险）：**
- 突然密集报道
- 权威机构发声
- 但基本面未实质变化
- 股价已提前下跌
- **上涨中突发暴跌+新闻 = 洗盘**

**真风险信号（物极必反）：**
- 已上涨很久，估值过高
- 过去有新闻驱动上涨
- 利好落空/不及预期
- **利好出尽 = 真风险**

#### 五维智能体对应

| 维度 | 职责 | 判断重点 |
|------|------|---------|
| **悟空** | 真假风险识别 | 基本面是否实质恶化？新闻是烟雾弹还是真信号？ |
| **沙僧** | 避害情绪监测 | 恐慌程度是否极端？是否进入避害模式？ |
| **白龙马** | 主力意图识别 | 吸筹vs出货？洗盘vs真跌？ |
| **八戒** | 概率校准 | 真风险概率？假风险被利用的概率？ |
| **唐僧** | 逆向布局决策 | 是否逆向操作？仓位如何控制？ |

#### 必须使用的分析流程

```
Step 1: 识别风险定义者
    ├─ 谁在定义这个风险/机会？
    ├─ 他们的动机是什么？
    └─ 他们的历史行为模式？

Step 2: 判断真假风险
    ├─ 基本面是否实质变化？
    ├─ 新闻是转移注意力还是真信号？
    ├─ 股价是否已提前反映？
    └─ 是否符合"物极必反"规律？

Step 3: 分析避害模式
    ├─ 散户是否进入避害模式？
    ├─ 恐慌程度是否足够极端？
    └─ 是否有足够多"被迫避害者"？

Step 4: 识别主力行为
    ├─ 长期打压 = 吸筹（真机会）
    ├─ 上涨中暴跌+新闻 = 洗盘（假风险）
    ├─ 利好出尽 = 出货（真风险）
    └─ 无人问津 = 布局（真机会）

Step 5: 逆向布局决策
    ├─ 假风险+避害极端 = 逆向买入
    ├─ 假机会+追涨狂热 = 逆向卖出
    ├─ 真风险+高位 = 跟随避险
    └─ 真机会+低位 = 果断布局
```

#### 经典案例记忆

- **黄金案例**：上涨中突发加息/停战新闻 → 暴跌 → 洗盘 → 反拉创新高
- **量化监管风暴**：行政打压 → 散户避害抛售 → 机构低位吸筹 → 反弹30%+
- **政策组合拳**：行政利好 → 散户追涨 → 机构高位出货 → 回调20%+

### 8.2 注意力捕兽夹框架

> **核心原则：高记忆行业 = 高预判埋伏区 = 反复收割注意力的"捕兽夹"**

#### 三层结构

```
第一层：记忆锚定（散户认知）
    ↓ 形成路径依赖
    "它以前涨过10倍" / "这次跌很多了" / "国家支持" / "总会二波"
    
第二层：预期埋伏（资金布局）
    ↓ 低成本点火
    给一点消息 → 拉几个涨停 → 制造熟悉感 → 激活旧记忆
    
第三层：收割兑现（资金离场）
    ↓ 旧资金自动接盘
    大量旧资金回流 → 筹码交换完成 → 行情结束
```

#### 捕兽夹识别矩阵

| 特征维度 | 捕兽夹行业 | 真主线行业 |
|----------|-----------|-----------|
| **市场记忆** | 全民爆炒过，记忆深刻 | 市场尚未形成完整记忆 |
| **叙事传播** | 短视频易传播，口号化 | 认知门槛高，初期难理解 |
| **筹码结构** | 上方套牢盘多，解套压力大 | 筹码干净，抛压小 |
| **散户参与** | 散户渗透率极高 | 散户参与度低 |
| **资金性质** | 存量资金反复收割 | 增量资金长期配置 |
| **行情特征** | 拉升快、波动大、龙头切换频繁 | 趋势慢、回调浅、龙头集中 |
| **二波预期** | "二波三波"文化盛行 | 无明确二波预期 |

#### 关键识别信号

**捕兽夹信号（高记忆行业）：**
- 曾出现大量妖股/连板股
- 形成固定口号（"万亿市场"、"国家战略"）
- 散户讨论度极高，短视频传播广
- 上方存在大量"等解套"资金
- 每次反弹都变成"卖压释放"
- 利好不断但始终无法走出持续主升

**真主线信号（低记忆行业）：**
- 初期看不懂、不相信、觉得贵
- 有真实产业扩张和资本开支
- 有业绩验证和利润传导
- 机构持续增配
- 全球产业链共振
- 龙头越来越集中

#### 五维智能体对应

| 维度 | 职责 | 判断重点 |
|------|------|---------|
| **悟空** | 行业本质判断 | 建设型行情 vs 收割型行情？ |
| **沙僧** | 记忆强度监测 | 散户记忆锚定有多深？ |
| **白龙马** | 资金性质识别 | 增量建仓 vs 存量收割？ |
| **八戒** | 赔率校准 | 高记忆 = 高拥挤 = 低赔率 |
| **唐僧** | 避坑决策 | 是否回避高记忆陷阱？ |

#### 必须使用的分析流程

```
Step 1: 评估行业记忆强度
    ├─ 是否全民爆炒过？
    ├─ 是否频繁上热搜？
    ├─ 是否形成固定口号？
    ├─ 散户渗透率多高？
    └─ 是否出现大量妖股？

Step 2: 判断筹码结构
    ├─ 上方套牢盘多不多？
    ├─ 是否存在"等解套"资金？
    ├─ 每次反弹是否变成卖压释放？
    └─ 筹码是否干净？

Step 3: 识别资金性质
    ├─ 资金是来建设还是收割？
    ├─ 是否有真实产业扩张？
    ├─ 机构是否在长期增配？
    └─ 还是纯资金推动、消息刺激？

Step 4: 评估赔率
    ├─ 高记忆 = 高拥挤
    ├─ 高拥挤 = 高预判
    ├─ 高预判 = 容易提前兑现
    └─ 提前兑现 = 捕兽夹结构

Step 5: 制定策略
    ├─ 高记忆+无业绩 = 回避
    ├─ 高记忆+利好密集 = 警惕
    ├─ 低记忆+产业趋势 = 布局
    └─ 无人问津+基本面改善 = 重点关注
```

#### 经典案例记忆

- **低空经济/商业航天**：叙事极强（国家战略、万亿市场、新质生产力）→ 短视频易传播 → 散户大量参与 → 上方套牢盘多 → 每次反弹都是卖压释放 → 捕兽夹结构
- **AI基础设施早期**：认知门槛高 → 初期看不懂 → 机构悄悄配置 → 筹码干净 → 真主线
- **光模块/HBM初期**：估值贵、像概念 → 散户不信 → 产业趋势明确 → 机构长期增配 → 走出大趋势

#### 核心公式

```
高记忆 = 高拥挤
高拥挤 = 高预判  
高预判 = 容易提前兑现
提前兑现 = 捕兽夹结构

真正的大机会，往往不在"最响"的地方
```

#### 五、政策指标在悟空模块的应用流程

```
Step 1: 识别政策信号
    ├─ 货币政策（降准/降息/MLF/LPR）
    ├─ 财政政策（地方债/专项债/基建）
    ├─ 产业政策（AI/新能源/半导体支持）
    └─ 监管政策（IPO节奏/窗口指导/打压）

Step 2: 判断政策意图
    ├─ 稳增长？→ 低位利好=真机会，高位利好=假机会
    ├─ 防风险？→ 高位打压=真风险，低位打压=假风险
    ├─ 促改革？→ 结构性机会
    └─ 控泡沫？→ 回避高估值板块

Step 3: 评估市场位置（行政点位识别）
    ├─ 高位+政策利好 = 利好出尽（假机会）→ 逢高减仓
    ├─ 低位+政策打压 = 利空出尽（真机会）→ 逢低布局
    ├─ 高位+政策打压 = 加速下跌（真风险）→ 避险
    └─ 低位+政策利好 = 反弹启动（政策底）→ 加仓

Step 4: 调整先验概率（传递给八戒）
    ├─ 政策利好 → 上调上涨概率（但需结合位置修正）
    ├─ 政策利空 → 下调上涨概率（但需结合位置修正）
    └─ 政策中性 → 维持原概率

Step 5: 输出政策因子
    ├─ 传递给八戒：政策因子权重（0-1）
    ├─ 传递给唐僧：政策底/顶信号（仓位调整）
    └─ 传递给白龙马：国家队动向（主力行为）
```
